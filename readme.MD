# 📝 Aplicación Todo List (Gestor de Tareas)

Aplicación web desarrollada con **HTML5**, **CSS3** y **JavaScript Vanilla** que permite gestionar un listado de tareas pendientes de forma dinámica. Este proyecto forma parte de un desafío académico para validar conocimientos sobre manipulación del DOM, arreglos de objetos y eventos.

---

## 🚀 Despliegue del Proyecto
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Abrir%20Sitio-blue?style=flat-square&logo=github)](https://jleival.github.io/desafio5-todo-list/)

---

## 🚀 Características Principales

* **Visualización inicial:** Carga automática de un arreglo con 3 tareas predefinidas al iniciar la página.
* **Agregar tareas:** Permite registrar nuevas tareas mediante un campo de texto (*input*) y un botón, inicializándose por defecto como no completadas.
* **Eliminar tareas:** Opción para borrar cualquier tarea del listado de manera individual, actualizando automáticamente el sistema.
* **Marcar como completadas:** Casillas de verificación (*checkbox*) interactivas que permiten tachar el texto de la tarea al completarla.
* **Contadores dinámicos:** Panel de resumen que actualiza en tiempo real el **Total de tareas** y el **Total de tareas realizadas** (utilizando métodos de filtrado de arreglos).

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la interfaz.
* **CSS3:** Estilos personalizados, diseño limpio y maquetación basada en la maqueta requerida.
* **JavaScript (ES6+):** Lógica de programación, manipulación del DOM, arreglos de objetos, funciones flecha y control de eventos.

## ⚙️ ¿Cómo ejecutar el proyecto?
No se requiere ninguna instalación de dependencias ni servidores locales avanzados. Sigue estos sencillos pasos:

Clona este repositorio o descarga el archivo index.html en tu computadora.

Abre el archivo index.html directamente en cualquier navegador web moderno (Google Chrome, Firefox, Microsoft Edge, etc.).

¡Listo! Ya puedes interactuar agregando, completando y eliminando tareas.
